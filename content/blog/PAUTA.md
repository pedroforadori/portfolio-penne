# Pauta do blog

Fila de temas para a skill `/blog-post` (e a rotina semanal). Sem argumentos,
a skill pega o **primeiro item com status `pendente`**. Pode reordenar,
editar ou acrescentar à vontade.

Formato de cada item:

```
- [status] Tema — palavra-chave: "…" — cases: slug, slug — notas
```

Status: `pendente`, `rascunho PR #N` (o agente marca), `publicado`, `descartado`.
